# Personal Portfolio

This is a personal portfolio website built as part of my web development coursework. It showcases my educational background, technical skills, and recent projects in software engineering.

## Features
* **Semantic HTML5:** Uses standard structural tags like `<header>`, `<main>`, `<section>`, `<nav>`, and `<footer>`.
* **CSS3 Styling:** Features external CSS with Flexbox for layout management and responsive design.
* **Responsive Design:** Adapts smoothly to mobile screens using CSS media queries.
* **Contact Form:** A basic form interface for user interactions.

## Project Structure
* `index.html` - The main structure and content of the website.
* `style.css` - The external stylesheet handling all visual presentation.
* `images/` - Directory containing the profile picture (`profile.jpg`).
